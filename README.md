An intelligent, AI-driven development assistant designed to automatically review code for logic, efficiency, runtime complexity, and edge-case coverage. It features real-time WebSocket communication to track upcoming competitive programming contests and seamlessly sync events to your calendar.  

🛠️ Tech Stack
Frontend: React.js, HTML5, CSS3  
Backend: Node.js, Express.js, WebSockets, Agentic API   Database & Caching: MongoDB, Redis   Languages: JavaScript, TypeScript
